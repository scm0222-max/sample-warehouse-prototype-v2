## 项目说明

本项目用于展示达芙妮样品仓的页面设计与交互流程。

主要包含：

在达人分销系统新增一个达芙妮样品仓

寄样出库链路：商务在系统里新增寄样申请，同步合思，合思审批通过后，我们把子申请单同步给聚水潭，聚水潭回传出库状态、物流单号等。

退样入库链路：达人退回后，商务在我们样品仓系统创建退样登记，我们把退货运单信息同步给聚水潭，仓库入库后聚水潭回传入库结果、入库 SKU、数量，用来匹配子申请单退样状态。
